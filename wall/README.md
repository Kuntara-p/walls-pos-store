# 🍦 Wall's Ice Cream POS & Store (ระบบจัดการยอดขายไอศกรีมวอลล์)

เว็บแอปพลิเคชันบริหารจัดการยอดขายไอศกรีมวอลล์ประจำโรงเรียน ออกแบบตามเอกลักษณ์ของ **Wall's (Heartbrand)** แบบ Mobile-first สำหรับคุณครูและผู้ดูแลโครงการใช้บันทึกยอดเงินสดในแต่ละวัน วิเคราะห์จุดคุ้มทุนแบบเหมาลอต และออกเอกสารบัญชี A4 พร้อมใบสั่งซื้อไอศกรีมเข้าตู้แช่อัตโนมัติ

---

## ✨ ฟังก์ชันหลัก (Key Features)

1. **📊 หน้าสรุปสถานะ (Dashboard)**:
   - แสดงสถานะ **ลอตที่ 1, ลอตที่ 2...** (เข้าใจง่าย ไม่ใช้รหัสสับสน)
   - แถบวัดยอดขายหลอดไอเย็นตู้แช่วอลล์ (Freezer Ice Gauge) 3 ระดับสี:
     - ❄️ ฟ้า: 0 - 80% ไอศกรีมเต็มตู้
     - 🔔 ส้ม: 80 - 100% เสียงเตือนใกล้หมดตู้ เตรียมสั่งของเพิ่ม
     - 🎉 เขียว: > 100% คืนทุนครบแล้ว กำไรล้วน ๆ
   - ปุ่มลัดปิดลอตและเริ่มรอบใหม่พร้อมบันทึกประวัติ

2. **🔢 บันทึกยอดเงินสด (Daily Cash Input & Numpad)**:
   - แป้นพิมพ์ตัวเลข (On-Screen Numpad) ขนาดใหญ่ สัมผัสง่ายบนมือถือ
   - ระบบคำนวณหักเงินทอนตั้งต้น (Float Money ฿500) อัตโนมัติ เพียงนับเงินทั้งหมดในกล่อง
   - ปุ่มบันทึกวันงดขาย (฿0) พร้อมเหตุผล (วันหยุดราชการ, ครูติดประชุม, กิจกรรมโรงเรียน, ฝนตกหนัก, ไอติมหมด)

3. **📑 ประวัติลอต & รายงานบัญชี A4 (History & Ledger)**:
   - ตารางสรุปบัญชีรายรับ-รายจ่าย แยกตามลอต (แสดงเฉพาะลอตที่ปิดรอบแล้ว ไม่นำลอตเปิดใหม่มาดึงกำไรติดลบ)
   - พิมพ์รายงานมาตรฐานขนาดกระดาษ A4 สวยงาม พร้อมช่องลงลายมือชื่อผู้จัดทำและผู้ตรวจสอบ (สามารถกดซ่อน/แสดงได้)
   - ส่งออกข้อมูลเป็นไฟล์ Excel (.xlsx) ครบทั้ง 2 ตาราง

4. **🍦 แคตตาล็อกสินค้า & ใบสั่งซื้อ (Products & Purchase Order)**:
   - รายการไอศกรีมวอลล์มาตรฐาน (คอร์เนตโต, แม็กนั่ม, แพดเดิลป๊อป, ท็อปเท็น, เอเชียนดีไลท์, แซนด์วิช ฯลฯ)
   - คำนวณกำไรต่อแท่งและกำไรยกลังแบบเรียลไทม์
   - วางแผนคำนวณงบสั่งของเหมาลอต (Lot Order Planner)
   - พิมพ์หรือดาวน์โหลดใบสั่งซื้อ (Purchase Order) เป็นไฟล์ PDF พร้อมส่งให้ตัวแทนส่งไอศกรีมวอลล์ได้ทันที

## 🚀 วิธีนำขึ้น GitHub และเผยแพร่บน Vercel

### วิธีที่ 1: อัปโหลดผ่าน GitHub Website (ง่ายที่สุด)
1. เข้าไปที่ [github.com/new](https://github.com/new) แล้วสร้าง Repository ใหม่ (เช่น ตั้งชื่อว่า `walls-pos-store`)
2. ในหน้าโปรเจกต์ กดที่ **"uploading an existing file"**
3. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป:
   - `index.html`
   - `app.js`
   - `styles.css`
   - `vercel.json`
   - `supabase_schema.sql`
   - `README.md`
4. กด **Commit changes**

### วิธีที่ 2: เชื่อมต่อและ Deploy บน Vercel
1. เข้าไปที่ [vercel.com](https://vercel.com) แล้วเข้าสู่ระบบด้วยบัญชี GitHub
2. กดปุ่ม **"Add New..."** -> เลือก **"Project"**
3. เลือก Repository `walls-pos-store` ที่เพิ่งสร้าง แล้วกด **Import**
4. ในหน้าตั้งค่าโปรเจกต์:
   - **Framework Preset**: เลือก **Other**
   - **Root Directory**: `./` (ค่าเริ่มต้น)
5. กดปุ่ม **Deploy**
6. รอเพียงประมาณ 30 วินาที Vercel จะสร้าง URL เว็บไซต์จริงให้ทันที เช่น `https://walls-pos-store.vercel.app` สามารถส่งลิงก์ให้คุณครูเปิดใช้งานผ่านมือถือหรือแท็บเล็ตได้ทุกที่!
